# التوثيق والمراجعة

## التوثيق

الافتراضي APA 7: مؤلف وتاريخ داخل النص، وقائمة مراجع، ومعرف DOI بصيغة `https://doi.org/` عندما يكون مسترجعًا. إذا فرضت المجلة نظامًا آخر، حوّل التنسيق فقط. التحويل لا يضيف مصادر.

كل مرجع يحتاج عنوانًا وسنة ومصدر استرجاع: DOI أو رابط الصفحة الرسمية التي فُتحت. المرجع الذي لا مصدر له لا يُكتب. لا تُستعمل معرفات نائبة مثل `10.1234/` أو `example.org`. لا تُنسب أرقام أو اقتباسات أو نتائج إلى مصدر لم يُفتح.

فحص القائمة:

```bash
python3 scripts/policy.py references --path references.json
```

## المراجعة المستقلة

لكل قسم مراجعة تُكتب بعد المسودة ولا تعتمد ادعاءات القسم دليلًا على صحتها. المعايير الأربعة إلزامية حتى لو كانت الإجابة أن المعيار غير منطبق أو أن البيانات غير متوفرة:

- المنهجية
- التحليل الإحصائي
- الأصالة
- الأخلاقيات

الحكم واحد من: مقبول، يحتاج تعديل، غير قابل للتحقق. إذا كانت البيانات غير متوفرة فلا تُكتب قيمة p ولا حجم أثر. المراجعة الأخلاقية تشمل الموافقة، والموافقة المستنيرة، والقُصّر، وبيانات الأداء، والإفصاح عن اشتقاق العمل من رسالة، وعدم اختلاق النتائج.

القالب: `assets/section-review.template.md`.

```bash
python3 scripts/policy.py review --path review.md --section المنهج
```
