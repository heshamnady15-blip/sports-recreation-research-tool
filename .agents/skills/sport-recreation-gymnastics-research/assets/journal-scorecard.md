# بطاقة مجلة

انسخ البطاقة لكل مرشح. التاريخ هو يوم فتح الصفحات.

- المجلة:
- ISSN الورقي والإلكتروني:
- الرابط الرسمي لصفحة الرسوم وتعليمات المؤلفين:
- رابط سجل Scopus لهذا الرقم:
- رابط DOAJ أو صفحة الوصول إن وُجد:
- تاريخ التحقق:
- حالة سكوبس: سارية / موقوفة / غير ظاهرة
- الربع وسنته كما في السجل، أو «غير ظاهر»:
- الرسوم على المؤلف، بالجملة المقتبسة من الصفحة الرسمية:
- نوع الوصول: ماسي / اشتراك بلا رسوم مؤلف / رسوم إلزامية
- لغة النشر:
- النطاق بجملة من صفحة المجلة:
- الصلة بهذا البحث (ترويح، جمباز للجميع، تربية بدنية، نشاط مكيّف):
- التحكيم: مزدوج التعمية أو غير ذلك كما هو مكتوب
- تطابق الرقم الدولي بين الموقع وسكوبس: نعم / لا
- الحكم: تُرشَّح / مؤجلة / تُستبعد
